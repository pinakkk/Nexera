INPUT: Report markdown, plan, evidence chunks.

OUTPUT: JSON only.
{

    "groundedness": 0.0-1.0,
    "coverage": 0.0-1.0,

SCORING:
- groundedness: % of claims with valid citations backed by evidence.
- coverage: % of sub-questions adequately answered.
- contradictions: 1.0 = all contradictions acknowledged; 0.0 = ignored.
- source_diversity: 1.0 = diverse sources; 0.0 = single source dominance.
- overall: weighted average (0.35*groundedness + 0.30*coverage + 0.20*contradictions + 0.15*source_diversity).

PASS threshold: overall >= 0.65.

RULES:
- Be strict. Do not inflate scores.
- Cite specific examples for low scores.
